# Aura

**A phone-first migraine tracker that wins by collecting less.**

One tap starts an attack and a second ends it. Time, weather and barometric pressure attach themselves, so nothing has to be typed mid-migraine. Afterwards a short walkthrough asks what is worth knowing, and every question can be skipped or answered "not sure". Over time Aura turns those taps into honest statistics: it tests weather, cycle and medication against the days *without* a headache, and says "no evidence" or "not enough data" rather than inventing a pattern.

## Why it exists

The tracker it replaces was a notes diary, and its failure was capture, not analysis: logging needed a computer, so entries were written late and half empty. Aura is designed around the worst moment to use an app, in the middle of an attack, with light and screens hurting:

- **One tap to start, one to stop.** The duration logs itself; nothing else is required.
- **Context nobody would backfill is attached automatically**: weather and pressure for every calendar day, from the location timeline, never from the phone.
- **Details are optional and come afterwards**, one question per page. "Not sure" is stored as unknown, never as "no", because a missing answer must not look like a negative one.
- **Works offline.** An attack captured without signal waits in a local outbox and syncs exactly once.

## What makes the numbers trustworthy

- **Headache days vs migraine days.** Every attack with recorded symptoms is checked against the [ICHD-3](https://ichd-3.org/) migraine criteria; the rest count only as headache days. It is labelled as "which criteria are met", never a diagnosis.
- **Control days.** Weather is stored for *every* day, so the trigger engine compares headache days with days without one, stratified by place and month (so season and country cannot pose as triggers), with Benjamini-Hochberg correction across factors. "No evidence" is reported as a real result.
- **Self-reported triggers are quarantined.** Old diary tags like "stress" were only ever written on headache days, so they are kept as beliefs and never counted as evidence.
- **Trends skip partial months**, which would otherwise fabricate an improvement, and every statistic reports `enough_data: false` instead of concluding from thin data.
- **Medication**: relief rate, time to relief, and the ICHD-3 medication-overuse day counts a neurologist would ask about.
- **Cycle**: a Mantel-Haenszel odds ratio for the perimenstrual window, excluding days whose cycle day cannot be known.

## Talk to your data with Claude

Aura exposes an [MCP](https://modelcontextprotocol.io) server at `/mcp`. The app computes every number deterministically and Claude only narrates it, so no health figure is ever generated by a model. The epistemic guardrails live in the tool descriptions themselves ("these are headache days, not migraine days", "self-reported triggers are beliefs, not evidence"), because that is what the model reads.

## Stack

- **Client:** TypeScript, React 19, Vite, Tailwind v4; an installable offline PWA with an outbox, Web Speech dictation, and a hand-drawn SVG head map.
- **Server:** Hono on a Cloudflare Worker with a nightly cron that backfills daily weather from Open-Meteo.
- **Data:** Cloudflare D1 (SQLite) with additive migrations.
- **Tests:** 330+ Vitest tests, including integration tests that run the real migrations on `node:sqlite`.

## Run it locally

```bash
npm install
cp .dev.vars.example .dev.vars   # sets a local ACCESS_PIN
npm run migrate:local
npm run build && npm run dev:worker   # http://localhost:8787
npm test
```

Deploying needs a Cloudflare account: create a D1 database, put its id in `wrangler.jsonc`, run `npm run migrate:remote`, set the PIN with `wrangler secret put ACCESS_PIN`, then `npm run deploy`.
